## Frontend `/api/chat` Contract

When `VITE_CHAT_MODE=live`, `sendChat(sessionId, message)` sends:

```http
POST /api/chat
Content-Type: application/json

{
  "sessionId": "<uuid-v4>",
  "message": "<trimmed user text>"
}
```

Expected response shape (validated client-side before rendering):

```json
{
  "mode": "parable",
  "text": "Non-empty assistant reply text",
  "locked": false
}
```

- `mode`: string (required)
- `text`: non-empty string (required)
- `locked`: boolean (required)
- Any non-2xx status or invalid response shape throws and shows the retryable error state without advancing the transcript.

## Running Locally & Connecting the Backend

**Mock mode (default):**

```sh
npm --prefix frontend ci
npm --prefix frontend run dev
```

**Live mode (proxied to Express):**

```sh
VITE_CHAT_MODE=live CHAT_API_TARGET=http://localhost:3000 npm --prefix frontend run dev
```

Vite (`frontend/vite.config.js`) proxies `/api` to `CHAT_API_TARGET` (default `http://localhost:3000`). Provider credentials stay server-side in Express.

**Same-origin production build:**

```sh
VITE_CHAT_MODE=live npm --prefix frontend run build
```

Serve `frontend/dist` from Express alongside `/api/chat`.
